# Léčivo, droga, nebo jed?

První funkční prototyp preventivně-výchovné webové aplikace pro projekt SOČ.

## Jak spustit
Stačí otevřít `index.html` v prohlížeči.

## Jak nahrát na GitHub Pages
1. Vytvořte nový repozitář.
2. Nahrajte soubory `index.html`, `style.css` a `app.js`.
3. V GitHubu otevřete **Settings → Pages**.
4. Jako zdroj vyberte větev `main` a kořenovou složku.
5. GitHub zobrazí veřejný odkaz na aplikaci.

## Co lze doplnit
- vlastní fotografie rostlin,
- interaktivní mapu,
- odborné citace a zdroje,
- další otázky a modelové situace,
- kontakty na odbornou pomoc,
- pretest/posttest pro výzkum SOČ,
- anonymní export výsledků (pokud bude metodicky vhodný).
